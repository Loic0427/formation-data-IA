# Briefs Python — Phase Maths & Python (S4-S5)

Trois briefs de niveau **imiter** qui ferment les dossiers [01-Syntaxe](../../../01-Fondamentaux/Python/01-Syntaxe/) et [02-POO](../../../01-Fondamentaux/Python/02-POO/) avant le passage à pandas en S6. Même univers que le reste du parcours : **NordRetail** et ses exports de ventes ([`../data/`](../data/)).

À ce niveau, l'apprenant reçoit un **exemple complet** et le reproduit sur un cas voisin : autre magasin, autre domaine, autre format de fichier. Le copier-coller de l'exemple est interdit ; les grilles de notation (dépôt privé `formation-corrections`) comparent les dépôts à l'exemple.

| Brief | Cours fermé | Durée | Compétences (niveau 1) | Kit |
|---|---|---|---|---|
| [PY1 — Premier script d'analyse : Valenciennes](PY1-syntaxe-analyse-magasin.md) | 01-Syntaxe | ½ journée | C8, C13 | [`kit-PY1/`](kit-PY1/) |
| [PY2 — Suivi des objectifs 2024 en objets](PY2-poo-suivi-objectifs.md) | 02-POO | ½ journée | C2, C8 | [`kit-PY2/`](kit-PY2/) |
| [PY3 — Consolider Valenciennes et Roubaix](PY3-pipeline-consolidation.md) | 01-Syntaxe + 02-POO | 1 journée | C8, C13, C2 | [`kit-PY3/`](kit-PY3/) |

Chaque kit contient l'exemple à imiter (script exécutable, exact sur les données fournies), un **squelette à compléter** (signatures en place, chaque `...` commenté, parties hors programme déjà écrites), les données de l'apprenant et, pour PY3, un script de contrôle qui compare le résultat à la référence. Les briefs donnent les valeurs de contrôle à chaque étape. Les corrigés et grilles vivent dans `formation-corrections/formation-data-analyst/briefs/PY1-…`, `PY2-…`, `PY3-…`.

Ordre conseillé : PY1 à la fin de la semaine Syntaxe, PY2 à la fin de la semaine POO, PY3 le dernier jour avant pandas.
